# 02 이력 get-or-create — POST /portfolio-history/create 두 번 (stage1 8절 근거 2)
# 포트폴리오 id 로 이력을 찾고, 없을 때만 만든다(portfolio-history.service.ts:13-22). front 는 편집 화면에 들어올 때마다 이 API 를 부른다(front profile-management.component.ts:65-73).
# 시나리오: (a·b) 이력이 이미 있는 포트폴리오에 두 번 → seed 이력 id 그대로 / (c) 준비: 이력이 없는 새 포트폴리오 / (d·e) 그 포트폴리오에 두 번 → 처음에 만들고 다음엔 같은 id.
# 한계: 같은 포트폴리오에 동시에 두 요청이 오면 둘 다 "없음"으로 보고 두 행을 만들 수 있다(유니크 제약·트랜잭션 없음, stage1 4절 "트랜잭션 없음"에서 추정, 실행으로 확인하지 않음).
