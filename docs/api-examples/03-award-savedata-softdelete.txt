# 03 수상 이력 저장·삭제 — POST /portfolio-history-award/saveData, DELETE /portfolio-history-award/deleteValue (stage1 8절 근거 6·4)
# saveData 는 front 가 보낸 블록 목록 전체를 받아 id 길이 > 5 면 기존 행 수정, 아니면 신규 생성으로 가르고, 저장 뒤 getData 로 다시 조회한 최신 목록을 돌려준다(award.service.ts:55-111). front 는 이 응답으로 목록을 통째로 바꾼다(front block-awards.component.ts:175-179).
# deleteValue 는 내용 1건을 softDelete 한다(award.service.ts:125-127, CommonEntity.deletedAt). 같은 3단 삭제가 학력·전시·기타에도 있다.
# 한계(stage1 9절 2): 저장은 map(async) 를 await 하지 않고 delay(200) 뒤 재조회한다 — 쓰기가 200ms 를 넘기면 옛 목록이 돌아올 수 있다. 신규 판별은 id 길이 휴리스틱이다.
# 새로 만든 행의 createdAt 은 실행 시각이다(fixture 행은 2023-12-01).
# 실행: 2026-10-18T10:12:20.823Z · 목업 서버 http://127.0.0.1:3000 (npm run mock:seed 직후 01→03 순서)
#
# 요약
#  03-a 200 · 수상[2022:1,2020:1]
#  03-b 201 · 응답 수상[2022:1,2020:1] 공모 선정[2023:1] · 임시 id '1'×3 → fbeb3fc5-1c61-4d47-b8cd-cb2348df0f1d / 750ffea5-667d-4dce-9159-26c0a79725be / d4dfe728-0ffc-4e2c-98f0-9aadeae0a3c2 · 기존 id 유지 true
#  03-c 200 · affected 1
#  03-d 200 · 수상[2022:1,2020:1] 공모 선정[2023:0] · "공모 선정/2023" 의 내용 0건
