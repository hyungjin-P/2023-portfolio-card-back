# 01 이력 일괄 조회 — GET /portfolio-history/getAllHistoryByPortfolioId (stage1 8절 근거 1)
# 한 번의 findOne 에 relations 로 6영역을 붙이고, 학력·전시·수상·기타 4영역은 제목 → 연도(subtitles) → 내용(values) 3계층까지 로드한다(portfolio-history.service.ts:24-44).
# order 에 층마다 createdAt ASC 를 겹쳐 지정한다(:37-42). fixture 시각은 2023-12-01 10:00 부터 행마다 1분씩 늘어 입력 순서가 곧 정렬 순서다.
# 응답은 엔티티를 그대로 돌려준다(응답 DTO 없음, stage1 4절). 인증 없이 portfolioId 만으로 조회된다(stage1 9절 1).
# 실행: 2026-10-18T10:12:20.728Z · 목업 서버 http://127.0.0.1:3000 (npm run mock:seed 직후 01→03 순서)
